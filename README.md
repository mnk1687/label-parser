# 批次标签解析工具 v0.2

从一份 ProdSheet 的 **TXT1 列**提取目标款号，再批量扫描同一批次的多个标签 PDF。按款号显示对应标签，导出按款号分组的汇总 PDF。**不再生成或保存 JSON 文件。**

## 使用

关闭旧窗口，双击 `启动解析工具.command` 打开新版本。

1. 点击「① 选择 ProdSheet」。读取全部页面的 TXT1，去重显示基础款号，并读取同一行的 Barcode 关系。TXT2 中的颜色、尺码不当作目标款号。
2. 点击「② 添加批次 PDF（多选）」。可同时选择多份文件，也可再次添加。与 ProdSheet 齐备后自动扫描全部文件的全部页面。
3. 左侧显示款号及匹配数量。点击一个款号，中间显示其标签来源文件、页码、匹配方式；点击标签可预览完整裁切。
4. 「全批次汇总并查看」导出所有款号的所有命中标签，不受当前筛选或勾选影响。「导出勾选项」导出整个批次中的勾选标签。
5. 导出后自动打开 PDF，也可点击「查看已导出 PDF」。每个标签单独一页，按 ProdSheet 中款号首次出现顺序分组，带款号书签。

文件列表支持多选移除。移除文件后需要点击「重新识别批次」。重复添加同一个文件不会重复扫描。作为款号来源的 ProdSheet 自动排除，不作为标签文件裁切。

原来的手动识别仍可使用：添加标签文件后，在上方输入款号并点击「按手动款号识别」。若已加载 ProdSheet，也可以使用其中的条码关系辅助匹配该款号。

## 匹配规则

- 优先按标签内的完整款号匹配，避免将 `FBL015-166-030` 误认为 `FBL015-166-03`。
- 标签没有印款号时，利用其 13 位条码与 ProdSheet 的同一行 Barcode → TXT1 关系关联。
- 图片型标签先 OCR 上方条码，必要时识别完整标签。不会猜测、更改或模糊修正 OCR 结果。
- 款号与条码关联冲突、一个框关联多个款号、边框缺失等会列为待检查项。
- 不以 TXT2、相同页码、相同位置或文件名猜测款号。生产单中同款不同尺码不会重复建立目标款号，但标签文件中各条实际标签保留。
- 空白联或仅包含条码的标签仍按原稿保留，不自动删除。
- 输出只有一个 PDF。内部返回统计数据供界面使用，不落地 JSON。不会修改原文件或覆盖已有 PDF。

## 运行环境

当前 Mac 已准备好 Python 环境和 Tesseract。移动源码项目后，启动脚本会建立 `.venv` 并安装依赖，需要 Python 3.10+ 和 Tkinter。OCR 依赖 Tesseract；其他 Mac 可用 `brew install tesseract` 安装。所有文档在本机处理。

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m label_parser --gui
.venv/bin/python -m label_parser --prodsheet '/路径/ProdSheet.pdf' '/路径/MAIN.pdf' '/路径/CARE.pdf' --output '/路径/批次汇总.pdf'
.venv/bin/python -m label_parser '/路径/MAIN.pdf' --keyword FBL015-166-03 --output '/路径/单款汇总.pdf'
.venv/bin/python -m unittest discover -s tests -v
```

返回码：0 成功，2 无可导出标签，3 已导出但存在异常或未匹配款号。其他错误为非零。

## 适配范围

当前针对本批次的 ProdSheet 表格结构、字母数字分段款号和青色边框标签。无框、倾斜或破损边框、其他表格布局需要适配。扫描型 ProdSheet 支持 OCR 尝试，未在本次真实生产单上验证扫描版识别精度；无法确认 TXT1 列时停止处理，不静默漏页。标签 OCR 可能错读，导出前请检查待检查项和预览。

为避免 PDF 中隐藏包含其他款号的内容，输出为 400 DPI 图片型 PDF，附款号导航书签。源文字不作为可搜索的隐藏文本写入。页尺寸按源裁切范围保留。

## 代码结构

- `label_parser/prodsheet.py`：TXT1 列提取、同一行条码关系
- `label_parser/core.py`：批量匹配、OCR、边框检测、PDF 导出
- `label_parser/gui.py`：批次文件选择、款号筛选、标签预览、汇总导出
- `label_parser/__main__.py`：GUI / CLI 入口
- `tests/`：解析与导出回归测试
